# v2025.11.01 – 2025-11-02

## New Feature: NFL Standings Board

A new standings board that displays division or conference standings with team-colored backgrounds.

### Features

- **Division Standings**: Display all teams in a division (NFC East, AFC North, etc.)
- **Conference Standings**: Display entire NFC or AFC conference
- **Team Colors**: Team backgrounds use official colors with contrast-checked text
- **Win Percentage**: Shows record and win percentage

### How to Enable

Add to your board rotation in `config/config.json`:

```json
"states": {
    "off_day": [
        "nfl_board",
        "nfl_standings",
        "clock"
    ]
}
```

Configure in `config/boards/plugins/nfl_board/config.json`:

```json
{
  "division": "NFC East",
  "display_type": "division",
  "scroll_speed": 0.2,
  "use_large_font": true
}
```

**Important:** The standings board requires `nfl_board` to be enabled - it depends on the main board for data.

See screenshots in the [README](../../README.md#screenshots).

## Performance Improvements

### Multi-Tier Caching

The plugin now caches different data types with appropriate expiration times:

- **Team data**: 24 hours (names, colors, logos rarely change)
- **Standings**: 4 hours (updated after games)
- **Live games**: 1 minute (scores update frequently)
- **Completed games**: 12 hours (final scores don't change)

This reduces startup time from 5-10 seconds to under 1 second, and serves cached data if the API is unavailable.

## Upgrade Instructions

**Follow these steps in order:**

### 1. Clear Cache Before Updating

```bash
scripts/sbtools/sb-cache-cleanup -d -f
```

**Why:** Root-owned cache files will prevent the plugin from upgrading.

**Important:** Do this before step 2.

### 2. Update or Install Plugin

**Update:**

```bash
python plugins.py sync
```

**Install:**

```bash
python plugins.py add http://github.com/kas21/nls-plugin-nfl-board
```

### 3. Update Configuration

Add standings configuration to `config/boards/plugins/nfl_board/config.json`:

```json
{
  "division": "NFC East",
  "display_type": "division",
  "scroll_speed": 0.2,
  "use_large_font": true
}
```

See [config.sample.json](../../config.sample.json) for full example.

### 4. Restart Scoreboard

```bash
sudo systemctl restart nhl-led-scoreboard
```
