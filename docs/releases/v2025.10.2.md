# v2025.10.3 – 2025-10-30

## Upgrade notes

**Required actions:**

1. **Clear cache before updating:**

   ```bash
   scripts/sbtools/sb-cache-cleanup -d -f
   ```

   **Why:** root-owned files will prevent the plugin from upgrading. This script cleans that up.

   **Applies to:** All versions upgrading to 2025.10.3+

1. **Update or Install plugin:**

   ### Update

    ```bash
    python plugins.py sync
    ```

   ### Install

    ```bash
    python plugin.py add http://github.com/kas21/nls-plugin-nfl-board
    ```

1. **Update NFL board configuration:**

   Add the following to your `config/boards/plugins/nfl_board/config.json`:

   ```json
   {
     "division": "NFC East",
     "display_type": "division",
     "scroll_speed": 0.2,
     "use_large_font": true
   }
   ```

   See [config.sample.json](../../config.sample.json) for full example.

1. **Add standings board to main config:**

   Add `"nfl_standings"` to the `boards_off_day` array in `config/config.json`:

   ```json
   "boards_off_day": ["nfl_standings", "clock", "weather"]
   ```

## Highlights

- **New NFL Standings Board** – Display division or conference standings with team colors, records, and win percentages. Includes scrolling support for long lists and NFL logo overlay.

- **Stale-While-Revalidate Caching** – Dramatically improves startup speed and resilience to API failures by serving cached data immediately while refreshing in the background. Caches scoreboard, teams, schedules, and team details.
